# Данные каталога «Свои — для своих»

`catalog.json` — готовая публичная выдача для существующего каталога Tilda. Это публикационный файл, не самостоятельная редактируемая база.

## Источник и состав

Источниками остаются оригинальные Google-таблицы Союза. Файл получен из уже работающего сборщика, без изменения текстов, телефонов, акций, ID и рубрик.

В исходной публикации 34 компании. Схема ответа — `schemaVersion: 2`, результат успешной сборки — `ok: true`. Логотипы и оформление существующий сайт пока берёт из своих блоков Tilda, не из этого файла.

Здесь не размещаются оригинальные таблицы, заявки посетителей, пароли и токены. Файл содержит только ту публичную выдачу, которая уже используется каталогом.

## Обновление

1. Получить новую успешную выдачу существующего сборщика.
2. Проверить схему, уникальность BusinessID и соответствие количества элементов полю `count`.
3. Заменить `catalog.json` целиком. Не редактировать отдельные компании здесь: исправления вносятся в оригинальные источники по правилам проекта.
4. При ошибке сборки не заменять предыдущую исправную выдачу. Не публиковать ответ `ok: false`.
5. При неизменном `hash` новое изменение файла не требуется.

На момент создания репозитория регулярное обновление ещё не настроено. Появление файла на GitHub само по себе не означает включённого расписания.

## Подключение и восстановление

Адрес публичного файла используется как `ENDPOINT` в существующем коннекторе блока 03 Tilda. Посетитель скачивает готовые данные; посещение не запускает сборку таблиц.

Для изменения данных файла повторная публикация Tilda не требуется. Изменение самого кода Tilda, оформления или встроенных логотипов требует отдельного обновления соответствующих блоков.

Для восстановления предыдущей исправной выдачи используется история `catalog.json` в GitHub. Нельзя помещать ключ GitHub в публичный блок Tilda.
